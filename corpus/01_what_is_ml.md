# What is Machine Learning?

Machine learning is a subfield of artificial intelligence that gives computers the ability to learn from data without being explicitly programmed for every task. Instead of writing hand-crafted rules, a machine learning model discovers patterns in training data and uses those patterns to make predictions on new, unseen data.

There are three main paradigms. Supervised learning trains on labelled examples, where each input is paired with the correct output — for instance, emails labelled as spam or not spam. Unsupervised learning works with unlabelled data and tries to find hidden structure, such as grouping customers into segments with clustering. Reinforcement learning trains an agent through trial and error, rewarding actions that lead to good outcomes, as in game-playing systems like AlphaGo.

The typical machine learning workflow has four stages: data collection and cleaning, feature engineering, model training with an optimization algorithm, and evaluation on held-out test data. Generalization — performing well on data the model has never seen — is the ultimate goal, and it is measured with metrics such as accuracy, precision, recall, and F1-score.
